Outer VR Landing Assist — local prototype 0.1.0
User goal: one-button near-ground landing using Quest, reduce simultaneous flight inputs.
Research: Ship Remote Autopilot2.0.0 has raw Keyboard/Gamepad controls, unconditional OnArrive callback and global notification clearing; do not enable it in the VR modset. No license file was found in the tagged source; retain research locally, do not redistribute its source/binary as our own. This implementation is independent, using game APIs and a separately testable control policy.
Design: two states Idle/Landing; own translation only while seated, alive, powered, valid locked target and physical ground within 120m; right-stick click (existing autopilot action) starts near-ground landing or cancels it. Far away and during existing autopilot flight, original control remains authoritative. Any stick movement, thrust, velocity-match, unbuckle, loss of ground/target/fuel, contact, scene change or death releases control. No arrival callback, route travel, save changes, ship teleport, camera transform writes, or global notification clearing.
Control: use existing landing alignment, target-body point velocity, actual landing-pad low point for clearance; approach <=5m/s, near-ground ~0.6m/s; settle horizontal speed/attitude before descent. Per-physics translation replacement at ShipThrusterController.ReadTranslationalInput; no double AddTranslationalInput. Shared layer ownership captured and restored when stopping.
Guard scope: physical ground on locked planet, slope <=30 degrees, max entry relative speed12m/s. Comet/Dark Bramble/Sun/interiors/unloaded terrain/water excluded. No obstacle route planning or flat landing-site search. Automatic body alignment can still move the view; not a proven motion-sickness fix.
Testing: compile against installed game/OWML; real policy deterministic vertical/horizontal descent traces; explicit no-ownership/manual-cancel/failed-gates; inspect patch targets. One startup/load check only if feasible, do not silently navigate user save. HMD/UI/flight acceptance remains manual.
Rollback: disable only Local.OuterVRLandingAssist using config with game closed; installed NomaiVR byte content stays unchanged.
